## 扩充筛选标准 (Inclusion Criteria for New Blogs)

新博客引入本资源库前必须满足：
1. **独立域名 (Root Domain)**：严禁使用免费二级域名（如 blogspot, wordpress.com 免费子域名权重极低）。
2. **原生表单结构**：具备明确的 `<input name="url">` 或 `<input name="website">` 字段。
3. **无恶意蜜罐**：不包含带 `trap`、隐藏恶意防爬诱饵字段。
4. **内容垂度高**：必须属于人工智能、大模型、后端开发、云架构、IDE 生产力工具或 API 协议领域。
