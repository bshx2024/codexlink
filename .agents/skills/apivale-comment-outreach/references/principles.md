# APIVALE 博客外链建设 5 大核心准则与白帽 SEO 哲学

本文档详细记录 APIVALE 博客外链建设的核心准则。本准则融汇了**哥飞/业内顶级白帽 SEO 经验**与 **APIVALE 实际业务场景**。

---

## 准则 1：按评论话题定页面，绝不按「想推哪篇」定

外链建设中最大的误区是无论别人在聊什么，都一股脑把当前最想推的页面硬塞上去。这会导致极高的博主拒审率和搜索引擎惩罚风险。

| 目标博文正在讨论的话题 | 对应留下的引流内页 |
| :--- | :--- |
| **某个具体模型**<br>（Claude Fable 5.2 / Qwen 4 / Kimi K3 / DeepSeek V4 / Gemini 4 等） | **该模型对应的那篇深度博文**<br>例如聊 Fable 5.2 留 `/blog/claude-fable-5-2-api-pricing-guide/`；聊 Qwen 4 留 `/blog/qwen-4-preview-api-token-plan-guide/`。 |
| **客户端/开发工具配置接入**<br>（Claude Code / Cursor / Codex CLI / OpenCode 配置） | **对应的 Setup 教程博文**<br>例如 `/blog/how-to-connect-kimi-k3-to-codex-cli/`、`/blog/how-to-connect-claude-opus-5-to-claude-code-cli/`。 |
| **平台级话题**<br>（API 中转、免 KYC、PayPal 充值、多模型路由、OpenRouter 替代） | **站级横评文章或首页**<br>例如 `/blog/openrouter-alternatives/`、`/blog/opencode-paypal-billing-api-proxy-guide/`，或直接留首页。 |
| **与任何一篇博文都对不上** | **留首页，或者本次放弃发布（宁缺毋滥）**。 |

---

## 准则 2：用 Google Search Console (GSC) 判定内页发布优先级

外链能够加快页面收录与权重传递，但**替代不了页面本身的质量**。

1. **第一优先级**：**「已收录、有曝光、排在 10 名以后」的内页**。这类内页最缺权重，单条高质量外链的效果立竿见影。
2. **第二优先级**：排在第 4 ~ 10 名的内页，通过高质量反链冲击前 3 名。
3. **未收录页面的处理**：没收录的内页应先检查站内互链与内容质量，不要盲目通过外链强推。如哥飞所言：“没收录，那是网页质量不行”。

---

## 准则 3：锚文本切忌全站高度统一

- **自写锚文本站点**：如果第三方平台允许自定义链接文本，务必使用**该内页标题里的核心词**（如 `Qwen 4 Max API pricing`、`connect Kimi K3 to Codex CLI`），避免全站 100 条全写 `apivale` 或 `AI API`。全站统一锚文本是触发算法降权（Over-Optimization）的最明显痕迹。
- **纯 URL / 显示昵称站点**：在绝大多数 WordPress 博客中，链接文字显示为评论者的 `Name`。此时必须挑选相关性最高的博文发，并让 `Name` 对应规范的 Persona（如 `Kenji Tanaka @ APIVALE`）。

---

## 准则 4：控节奏、先筛博客、域名防重

1. **一站一篇，严防同域泛滥**：同一个外部博客绝不在多篇文章中反复出现同一个域名。
2. **博客质量初筛**：
   - 检查博客是否有真实读者与正常留言；
   - 评论区是否清一色是赌博、灰产或纯垃圾广告。如果是垃圾场，果断放弃。
3. **节奏分散**：单批发布量控制在每日 5~10 条，避免短时间内突然对几十个内页集中轰炸。

---

## 准则 5：周期性验收与预算淘汰机制

1. **1 个月后验收**：回到 GSC 按页面维度观察曝光量和平均排名曲线。
2. **优胜劣汰**：
   - 持续上升的内页可追加优质外链维持优势；
   - 无任何波动的页面说明受制于内容质量或外部竞争度，应及时暂停针对该页面的外链投入。
